# CODEALPHA_AgeCalculator
Responsive Age Calculator using HTML, CSS &amp; JavaScript.
#Age Calculator

A sleek and interactive Age Calculator web application that calculates a user's exact age based on their date of birth. The application features real-time validation, animated results, birthday countdown, and a modern dark-themed user interface.

#Features
Calculate age in years, months, and days
Display total days, weeks, and months lived
Next birthday countdown
Input validation and error handling
Responsive design
Smooth animations
Modern UI/UX

#Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
